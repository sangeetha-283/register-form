📌 Project Description

This project is a basic registration form built using HTML, CSS, and JavaScript.
It includes input fields for Name, Email, and Password, and performs real-time form validation using JavaScript before submission.

💡 Features

Validates that the Name field is not empty and contains only letters.

Checks that the Email field follows a valid email format (e.g., example@gmail.com).

Ensures the Password field:

Has at least 8 characters

Contains at least one uppercase letter, one number, and one special character

Displays alert messages for invalid inputs.

Prevents form submission until all validations pass.

🛠️ Technologies Used

HTML5 – structure of the form

CSS3 – basic styling

JavaScript (ES6) – input validation logic
